## Why I built it

I created Myna to be able to have a podcast.

I'm convinced that a podcast is a great way to communicate, but it takes a lot of work. And I'm better at writing than at speaking in front of a microphone. With these two facts in mind, I started building two things: an app that turns text into speech, and an app that trains a voice to sound like my own.

I set three rules from the start. Nothing leaves the device: no upload, no account, and it works offline. Since a voice is a powerful thing to copy, no voice can be used without its speaker's recorded consent. And there is no generative AI in the studio: the words are always mine. The only model is the voice, and it reads my text as written.

<Callout title="What is a neural voice?">

A neural voice is a program that has listened to hours of one person speaking and learned to imitate them. You give it text, it gives back sound. In Myna, each voice is a file of about 63 MB that your browser runs by itself: no server ever hears your script.

</Callout>

## Why Myna

My personal projects are named after birds, my professional ones after fish. The myna is a bird, and I picked this one because it can reproduce sounds and voices.

## What I built

- **Myna**, an app you install from the browser. You write the script, Myna reads it, masters the audio and exports an MP3 with chapters, plus what you need to publish the feed.
- **Myna Atelier**, a desktop app for Mac, Windows and Linux that trains your own voice from 30 to 60 minutes of recordings, on your machine.
- **voicelab**, the command-line tool behind Atelier: it checks the recordings, trains the voice and exports it as a single `.voice` file.

**The voice runs in the browser.** The voices are Piper models, run by ONNX Runtime Web in a Web Worker. On an M-series Mac, an episode renders 15 to 20 times faster than real time. The details are in the [TTS architecture](https://podcast.iscor.me/docs/architecture/tts) page.

<Callout title="What is a Web Worker?">

A web page normally does everything on a single track, so heavy work makes it freeze. A Web Worker is a second track running beside it. Myna makes the voice there, so you can keep typing while it speaks.

</Callout>

**The sound of a real show.** The volume is measured to the broadcast standard (EBU R128), then compressed and limited, and the music fades under the voice. See the [audio pipeline](https://podcast.iscor.me/docs/architecture/audio-pipeline).

**Consent, checked in the recording itself.** Every voice includes a recording of its speaker reading a consent sentence with a random code. Atelier checks it before training, and Myna refuses a voice without it. See [consent and provenance](https://podcast.iscor.me/docs/architecture/consent).

**Everything stays local.** Episodes are stored in the browser, and the voice engine stays available offline.

**One format, four programs.** The web app, the trainer, the Mac app and the Windows and Linux app all read the same files, described by shared schemas and tested against the same examples.

<Callout title="What is a JSON Schema?">

A written rule for what a file must contain: which fields, and of which type. Four programs read Myna's files, and the schemas make sure they all agree on what a valid file looks like.

</Callout>

## What was hard

I worked with tools and technologies I had never heard of before: speech models, audio mastering, desktop apps. Building it is how I understood the concepts behind my first, simple idea.

- Running the model in the browser moved the hard part from servers to packaging. Using several processor cores needs special headers, and working offline means caching about 33 MB.
- With four programs reading the same files, the only way to keep them honest was to test each one against the same examples.
- Consent has to be checked in the recording itself, because anyone can edit a file's details.

After some iterations, I reorganised the project to make it more professional, and gave it a proper design.

## What's next

I'm very proud of the result, and I can't wait to improve it, starting with voices that sound less robotic. And then, write the scripts of my episodes.
